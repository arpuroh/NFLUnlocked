One-time
setup

Do this once. The site updates itself forever after — game-day refreshes on Sunday, the roast column Tuesday morning, a daily sweep for waiver moves. Nobody touches a spreadsheet again.

1

Create a free Yahoo developer app

Go to developer.yahoo.com/apps/create and sign in with the Yahoo account that is actually in the league. Set:

  • Application name: NFL Unlocked (anything works)
  • Redirect URI:
  • API permissions: Fantasy Sports → Read

Yahoo hands back a Client ID and Client Secret. Keep that tab open.

2

Add the keys to Vercel

In Vercel → your project → Settings → Environment Variables, add YAHOO_CLIENT_ID and YAHOO_CLIENT_SECRET, then redeploy. This is what makes the button below work.

3

Authorize once

Click below, sign in to Yahoo, hit Agree, and you get a refresh token plus instructions for the last step. It is shown once and stored nowhere.

🏈 Connect Yahoo League

4

Add GitHub secrets and run it

In the GitHub repo → Settings → Secrets and variables → Actions, add four:

  • YAHOO_CLIENT_ID — from step 1
  • YAHOO_CLIENT_SECRET — from step 1
  • YAHOO_REFRESH_TOKEN — from step 3
  • ANTHROPIC_API_KEY — from console.anthropic.com, powers the weekly roast

Then: repo → Actions → Update league data → Run workflow. Within a minute the site swaps demo data for your real league and stays current on its own.

Wire it once. Let it humiliate everyone automatically.
